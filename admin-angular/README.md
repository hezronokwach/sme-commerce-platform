# Admin (Angular)

Shop owner and staff app: login, products, stock, orders, payments, settings.
Angular 22 (standalone components, Vitest). Needs Node 22.22.3+ or 24.15+.

## Run it locally

1. Start Postgres and the backend (from `backend/`): `docker compose up -d`, then `./mvnw spring-boot:run`.
2. From this folder, once: `npm install`.
3. `npm start`, then open http://localhost:4200.

`npm start` runs `ng serve` with `proxy.conf.json`: calls to `/api/...` are forwarded to the backend on
http://localhost:8080, so the browser sees one site (no CORS needed locally).

## Other commands

| Command | Does |
| --- | --- |
| `npm test` | Unit tests (Vitest) |
| `npm run build` | Production build into `dist/` |
| `npm run generate-api` | Regenerates `src/app/api/` from `../docs/api/openapi.json` |

## The API client (`src/app/api/`)

Generated by ng-openapi-gen; don't edit it by hand. After the backend API changes:

1. In `backend/`, run `./mvnw verify`. `OpenApiTests` saves the current description to `docs/api/openapi.json`.
2. Here, run `npm run generate-api`.
3. Commit both, so the diff shows how the API changed.

Calling an endpoint: inject `Api` and call `await api.invoke(productList, { status: 'ACTIVE' })`.
Each endpoint is one function in `src/app/api/fn/`, named after its operation (`productList`, `authLogin`, ...).
